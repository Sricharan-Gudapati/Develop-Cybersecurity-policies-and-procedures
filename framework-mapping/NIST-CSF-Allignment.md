# NIST Cybersecurity Framework (CSF) Alignment Matrix

## 1. Overview
This document maps our organization's internal cybersecurity policies and operational procedures to the core functions of the **NIST Cybersecurity Framework (CSF 2.0)**. It serves as a cross-reference for internal audits and compliance verification.

## 2. Framework Mapping Matrix

| NIST CSF Function | Core Category | Implemented Policy / Procedure | Status |
| :--- | :--- | :--- | :--- |
| **Govern (GV)** | Organizational Governance | README & Repository Structure | Completed |
| **Protect (PR)** | Identity Management & Access Control | `policies/Access-Control-Policy.md` | Completed |
| **Detect (DE)** | Anomalies and Events | `procedures/Incident-Response-Playbook.md` | Completed |
| **Respond (RS)** | Incident Analysis & Mitigation | `procedures/Incident-Response-Playbook.md` | Completed |
| **Recover (RC)** | Incident Recovery Planning | `procedures/Incident-Response-Playbook.md` | Completed |

## 3. Compliance Verification Notes
* **Access Control:** Enforces least privilege, mandatory multi-factor authentication, and scheduled quarterly user access reviews.
* **Incident Response:** Provides a structured, 6-phase lifecycle covering preparation through post-incident lessons learned to ensure continuous resilience.
